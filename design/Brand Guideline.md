# Essia Zarrouk — Brand Guideline

**Visual system: "Terminal Strike"**
Version 1 · 2026

The rules that keep every page consistent — utilitarian, grid-led, monochrome with a single acid-green strike. Built for a marketing & branding portfolio that reads like a control panel.

> **Signature line:** *not new here, but always improving*

---

## 01 · Logo & Wordmark

| Asset | Form |
|---|---|
| **Primary wordmark** | `Essia Zarrouk` — Helvetica Neue, weight 700, tracking −0.03em |
| **Monogram** | `EZ` — monospace, used as favicon / compact mark, in acid green |
| **Toolbar lockup** | `Essia Zarrouk™` — monospace, uppercase, the ™ in acid green |

**Do**
- Set tight (−0.03em). Keep clear space ≥ the cap-height on all sides.
- The wordmark may bleed off the canvas edge as a hero device.

**Don't**
- No outlines, gradients, shadows, or recoloring the name itself.
- Green is reserved for the ™ and accents — never the full wordmark.

## 02 · Color

| Token | Hex | Role |
|---|---|---|
| Ink | `#000000` | Page background |
| Panel | `#111111` | Frame / card background |
| Surface | `#1A1A1A` | Image slots, inset surfaces |
| Hairline | `#333333` | Borders & rules |
| White | `#FFFFFF` | Primary text |
| Mute | `#CCCCCC` | Body text |
| Grey | `#777777` | Metadata, muted labels |
| **Strike** | `#C6FF00` | Accent — **one hit only** |

**Rule —** green is a strike, not a fill. One green element per viewport: the active state, a single CTA, or a key phrase. Everything else is mono.

---

## 03 · Typography

**Typefaces**
- **Display / Body:** Helvetica Neue
- **Labels / Data:** Monospace (SF Mono / ui-monospace)

**Scale**

| Role | Size | Weight | Tracking / Leading |
|---|---|---|---|
| Display | 64–104px | 700 | −0.04em |
| Section heading | 36px | 700 | −0.02em |
| Body | 15–16px | 400 | 1.8 line-height, 430–560px measure |
| Mono label | 11–13px | 400 | 0.12em, UPPERCASE |

Mono labels carry brackets and indices: `[ Label ] · Metadata · 01 / 12`

## 04 · Grid & Layout

| Property | Value |
|---|---|
| Frame padding | 24–28px |
| Label gutter | 150px |
| Section rhythm | 48px, separated by a hairline |
| Borders | 1px · `#333333` |
| Corners | Square · 0 radius |
| Modular grid | ~90px columns, kept faintly visible |

**Pattern —** every section = a `[bracket]` tag + label, a hairline rule, then a 150px mono gutter beside the content. Sharp corners everywhere.

---

## 05 · Components

- **Buttons** — Primary: solid green fill, black text, mono uppercase (`Enter profile ↗`). Ghost: 1px white border, white text.
- **Tabs** — Active = green fill + black text + bold. Default = 1px `#333` border, grey text.
- **List rows** — Hover/active row fills green (black text), arrow `↗` slides right. Inactive rows are grey on a hairline.
- **Image slots** — `#1A1A1A` fill, 1px `#333` border, square. Green `▢ drop image` hint, bottom-left.
- **Section tag** — `[ 01 ]` in green + uppercase mono label + hairline rule across.
- **Orbit ring** — Rotating central portrait with orbiting labels (Personal page signature).

---

## 06 · Motion

**Easing: 0.6–0.8s · soft in / clean out · no spring, nothing bounces or spins.**

1. **Page-load intro** — Nav + hero fade in, in sequence; wordmark clip-reveals from a mask.
2. **Scroll reveals** — Elements fade up from slightly below, staggered a beat apart.
3. **Hover / click standout** — Row fills green, arrow slides right, image zooms in its frame.
4. **Horizontal & orbit** — Portfolio pins then pans sideways; personal ring rotates slowly.
5. **Custom cursor** — A lagging dot that grows over links and interactive rows.
6. **Easing** — Slow, deliberate, soft in / clean out.
